# K-Means Clustering - Student Performance

## Project summary
Hands-on unsupervised learning practice using K-Means to explore student habits and performance patterns.

## Files
- k-means(student-performance).ipynb: Main K-Means clustering workflow.
- unsupervised-learning.ipynb: Additional clustering exploration and notes.
- student_habits_performance.csv: Source dataset.

## Setup
Install the common data science stack:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

## Run
1. Open the notebooks in Jupyter or VS Code.
2. Run cells top to bottom.

## Notes
- Keep the CSV in the same folder as the notebooks.
- If you change features, re-run scaling before K-Means.
