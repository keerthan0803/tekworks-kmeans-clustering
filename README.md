# Unsupervised Learning - Day 23

## Overview
This folder contains notebooks and data used for unsupervised learning practice with student performance data.

## Contents
- k-means(student-performance).ipynb: K-means clustering work on student performance data.
- unsupervised-learning.ipynb: Additional unsupervised learning exploration.
- student_habits_performance.csv: Dataset used by the notebooks.

## How to use
1. Open the notebooks in Jupyter or VS Code.
2. Ensure required Python packages are installed (e.g., pandas, numpy, matplotlib, seaborn, scikit-learn).
3. Run the cells in order.
